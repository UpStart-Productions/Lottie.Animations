# Lottie.Animations

Lottie animations recreated — or sourced directly — from LottieFiles preview pages, without their paid-download gate.

Each animation lives in `animations/<name>/`:
- `<name>.json` — the final Lottie file
- `preview.gif` — a quick visual preview
- `NOTES.md` — how that one was made

See `CLAUDE.md` for the full workflow, the lessons learned building these, and Jeff's standing preferences for how they should look and feel — read that before generating a new one.
