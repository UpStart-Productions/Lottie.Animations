# Heart Burst

Hearts floating up and fading — Instagram-reaction style.

- **Source:** the real original file, found directly via the LottieFiles preview page's own network requests — see `CLAUDE.md`, "Step 0"
- **Method:** used as-is, not recreated. Only edit was stripping the baked-in opaque white background solid layer so it composites transparently for overlay use
- **Loop:** 141 frames @ 60fps (~2.35s), 5 heart shape layers with staggered start times
- Went from URL to delivered file in one pass — no review rounds needed
