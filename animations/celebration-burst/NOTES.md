# Celebration Burst

Confetti bursting from three cannons (left, right, top) — streamers, circles, stars, rectangles, and squares scattering and falling.

- **Source:** the real original file, found directly via the LottieFiles preview page's own network requests — see `CLAUDE.md`, "Step 0"
- **Method:** used as-is. No background layer at all in this one, so no cleanup was even needed — it's already transparent
- **Loop:** 370 frames @ 70fps (~5.3s), 3 cannon precomps driving 5 shared particle-shape precomps (streamers/circles/stars/rects/squares), each instanced twice with staggered timing
- Went from URL to delivered file in one pass — no review rounds needed
